# Sunday Morning - Lyric Visualizer

A notebook-themed web lyric visualizer for "Sunday Morning", featuring word-by-word synchronized lyrics, dynamic floating photo animations, and an automated dark mode theme switch. Built using HTML, CSS, and Vanilla JavaScript.

## 🚀 Live Demo
You can view and play the live project here: https://clwdyttghub.github.io/sunday_morning/

## 🛠️ Built With
* **HTML5** - For the core structure and audio element playback.
* **CSS3** - For the notebook-paper design, fluid animations, and dark mode transitions.
* **Vanilla JavaScript** - For precise timestamp management and dynamic photo injection.

## 📂 Project Structure
* `index.html` - The main entry point containing the webpage markup.
* `style.css` - Custom styling for the notebook layout and layout rules.
* `script.js` - Contains the logic for lyric timing, photo generation, and theme switches.
* `sunday-morningg.mp3` - The background audio track.
